# Sportfolio Growth Loop

## Objective
Prove that PE teachers who do not know Toby will voluntarily use a useful zero-login tool and then progress into Sportfolio.

## Loop
`TEACHER PAIN -> FREE UTILITY -> DISCOVERY -> VALUE -> SPORTFOLIO HANDOFF -> ACTIVATION -> RETURN -> LEARN -> IMPROVE`

## Current constraint
Discovery and first value occur too late. The public site explains the product, but its primary action is sign-in. A stranger cannot experience useful value before committing.

## Primary acquisition experiment
**PE Report Assistant** — a public, zero-login utility that turns structured teacher judgement into a draft PE report comment. It must not use pupil-identifiable data and must clearly require teacher review.

Pass: qualified strangers use the utility and voluntarily continue toward Sportfolio.
Strong signal: repeat use, class-scale intent, account/pilot request, referral, or WTP.

## Gates
- Do not add authenticated product features until acquisition/activation evidence earns them.
- Do not store pupil names or report content in the acquisition utility.
- Do not position generated wording as autonomous assessment.
- Teacher judgement remains authoritative.
- Track utility use and handoff where existing analytics allow.
